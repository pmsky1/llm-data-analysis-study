# 데이터분석 프로젝트

## 매달 1,000달러, 지금 살까 기다릴까?

- 매월 첫 거래일에 1,000달러를 나스닥100에 바로 투자하는 방법과 하락을 기다렸다가 매수하고 목표 수익에 매도하는 방법을 비교할 예정입니다
- 대기 자금의 이자는 0%로 가정하고, 9개 매수·매도 조합의 최종 자산과 대기 기간, 매매 횟수를 살펴볼 계획입니다
- 나스닥100 가격지수와 배당 포함 총수익지수의 1999년 4월~2026년 10월 자료를 확보했습니다
- 투자 시작 월을 1999년 4월~2021년 9월로 바꿔 가며 각각 5년간 투자한 270개 사례를 비교할 예정입니다
